
Algorithme CalculTemps

Variables
    L1, L2 : réel
    Dy, Dx : réel
    vitesse1, vitesse2 : réel
    temps1, temps2, tempsTotal : réel

Début

    L1 ← 6;
    dy ← 10 - L1;
    dx ← 3;

    vitesse1 ← 5;
    vitesse2 ← 2;

    L2 ← √(dy² + dx²);

    temps1 ← L1 / vitesse1;
    temps2 ← L2 / vitesse2;

    tempsTotal ← temps1 + temps2;

    Afficher tempsTotal

Fin
